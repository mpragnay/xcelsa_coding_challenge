## Function Optimization Challenge
Problem Statement: Given a function(f) in python(interpreted language), goal is to output a function(f') that is functionally equivalent and also is faster(runtime) than the original function

### Thoughts
Some sort of compiler optimization.
Key point is we don't need to have the most optimal implementation of this function.
Go through a list of all viable compiler optimizations(phase ordering problem), and pick any one of them and apply it to the original function.
Probably some trial and error loop on this to evaluate if runtime improved.

#### Compiler optimizations possible in python
Dead Code elimination
Loop unrolling
Branch Prediction
